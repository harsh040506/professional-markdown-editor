## Packages that need a note

- **dompurify** 3.4.17: (MPL-2.0 OR Apache-2.0). Offered under either license; this project uses it under Apache-2.0.
- **elkjs** 0.9.3: EPL-2.0. The layout engine that Mermaid loads, only when a diagram asks for it, as a separate lazy chunk. It is distributed unmodified; its source is at https://github.com/kieler/elkjs.
- **mathml2omml** 0.5.0: LGPL-3.0-or-later. Used only to turn equations into native Word equations when a .docx is exported. It is loaded as a separate file (a lazy chunk of the build) on first use and is not part of the editor itself, so it can be replaced by another build of the library: edit the `mathml2omml` entry in `package.json`, run `npm install` and `npm run build`. Its full license text is below, and its source is at https://github.com/fiduswriter/mathml2omml.
